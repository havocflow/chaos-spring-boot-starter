# Code of Conduct

## Our Pledge

HavocFlow is an open, welcoming community. Everyone who participates — by filing issues, opening pull requests, writing documentation, or joining discussions — is expected to treat others with respect and professionalism.

## Expected Behaviour

- Be kind, patient, and constructive in all interactions.
- Assume good intent; ask for clarification before assuming the worst.
- Give and receive feedback graciously — critique ideas, not people.
- Respect differing opinions and experiences.
- Focus on what is best for the community and the project.

## Unacceptable Behaviour

- Personal attacks, insults, or demeaning comments.
- Publishing others' private information without explicit permission.
- Any conduct that a reasonable person would consider inappropriate in a professional setting.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this standard. Instances of unacceptable behaviour may be reported by opening a GitHub issue marked **[conduct]** or by contacting the maintainers directly via the repository.

Maintainers reserve the right to remove comments, close issues, or ban contributors who repeatedly violate this code of conduct.

## Scope

This code of conduct applies to all project spaces — GitHub issues, pull requests, discussions, and any other official project channels.

---

We believe that a respectful community produces better software. Thank you for helping keep HavocFlow a positive place to contribute.
